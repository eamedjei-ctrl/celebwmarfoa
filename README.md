# Happy Birthday, Mrs. Marfoa 💜

A birthday site for Ama Marfoa Ankomah:
**Welcome → a flip-through storybook (Elton's note) → blow out the candles → the party**
(fireworks, balloons you can pop, and her photos in a beating heart, a 3D carousel, film strips, drifting polaroids and a gallery).

Music plays after "Open your surprise": *Happy Birthday* once, then sweet melodies on loop
(Canon in D, Für Elise, and an original, *Marfoa's Waltz*). The tracks are generated by
`scripts/make-music.py` (music-box synth, public-domain tunes + one original).

## Run

```bash
npm install
npm start        # http://localhost:4321  (PORT in .env)
```

## Media lives in the bucket

Photos, videos and music are **not** in this repo. They're served from the bucket via the API:

- **Upload / delete:** `http://localhost:4321/upload` (needs `ADMIN_KEY` from `.env`).
  Images/videos go to the gallery in upload order; audio files become the playlist (first file plays first, then the rest loop).
- **Bucket backend:** a local `./bucket` folder by default. Set `S3_*` in `.env` to use Cloudflare R2, Supabase Storage or AWS S3 (see `.env.example`).
- **Move local → cloud:** fill in `S3_*`, then `npm run migrate` copies everything from `./bucket` into the cloud bucket and verifies it.

API: `GET /api/media` · `POST /api/media` (multipart `files`, header `x-admin-key`) · `DELETE /api/media/<key>` · `GET /media/<key>` (range-capable streaming).

## Files

- `public/index.html` markup for all four scenes · `styles.css` base look · `animations.css` motion
- `public/app.js` scenes, storybook, cake, photo showcases, lightbox, music playlist
- `public/fx.js` sparkle trail, tap bursts, floaters, fireworks, balloons, tilt, magnetic buttons
- `server/` Express API + bucket adapters (local / S3-compatible)
